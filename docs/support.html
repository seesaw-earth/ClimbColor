ClimbColor Support

ClimbColor is a free, open-source iPhone app for highlighting same-color climbing holds from a wall photo.

Quick help

  • Take a wall photo or choose a photo from your library.
  • Wait for on-device hold detection to finish.
  • Tap a hold to highlight holds with a similar color.
  • Use the edit controls to add or remove holds from the selected route.
  • Use Save or Share to export an annotated image.

Privacy

Detection and color analysis run on device. ClimbColor does not use developer-operated accounts, analytics, advertising, or an image-upload service.

Support and bug reports

For questions, bug reports, or feature requests, please use the ClimbColor GitHub Issues page .

Source code

ClimbColor is free and open source. The source code and trained Core ML model are available at github.com/seesaw-earth/ClimbColor .
